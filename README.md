# Black Myth: Wukong Cheat Sheet

A self-contained, static checklist web app inspired by the interaction model of the Dark Souls Cheat Sheet.

## Run locally
Open `index.html` in any modern browser.

## Deploy
Upload `index.html` to any static host (GitHub Pages, Netlify, Cloudflare Pages, etc.).

## Features
- Mobile-first phone layout with larger tap targets
- Sticky bottom navigation and one-tap "Next unchecked"
- Horizontally scrollable filter chips on narrow screens
- Mobile profile sheet and safe-area support
- Direct detail-page wiki links for bosses, NPCs, items, armor, spells, Curios and locations
- Six chapter playthrough checklist
- Required / missable NPC interaction tracking
- Important armor, Vessel and gear reminders
- Four-Loong hidden boss progression and Loong Scales
- Five Skandhas quest tracking
- One-run missables such as Auspicious Lantern and Apramana Bat
- Category filters for NPCs, bosses, armor, gear, Spirits, Transformations, Curios, collectibles, quests, secrets and missables
- Secret-area / missable / boss tagging
- Per-profile local progress
- Search and collapse/expand controls
- Import/export JSON backups
- Responsive mobile layout
- No build step and no external runtime dependencies
